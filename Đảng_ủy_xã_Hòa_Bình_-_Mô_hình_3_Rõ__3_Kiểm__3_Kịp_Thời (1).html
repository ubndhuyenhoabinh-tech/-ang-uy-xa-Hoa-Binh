Triết Lý 3 Rõ – 3 Kiểm – 3 Kịp Thời

● 3 RÕ: Rõ việc (Sản phẩm cụ thể) – Rõ người (1 đầu mối chịu trách nhiệm) – Rõ tiến độ (Có mốc thời gian & mã màu).
● 3 KIỂM: Kiểm việc (Đúng kết luận/nghị quyết) – Kiểm người (Chủ trì & phối hợp) – Kiểm tiến độ (Sắp đến hạn, nguy cơ chậm).
● 3 KỊP THỜI: Kịp thời chỉ đạo – Kịp thời tháo gỡ điểm nghẽn – Kịp thời chịu trách nhiệm.

Cấu Hình Đồng Bộ Dữ Liệu Dùng Chung

Hướng dẫn (chỉ cần làm 1 lần cho cả đơn vị):
  1. Truy cập console.firebase.google.com, tạo dự án mới (miễn phí) → tạo Cloud Firestore (chế độ Production).
  2. Vào Build → Authentication → Get started, bật phương thức đăng nhập Email/Password.
  3. Vào Project settings → General → Your apps → tạo Web App để lấy 6 thông số cấu hình.
  4. Vào Firestore → Rules, dán quy tắc bảo mật ở khung bên dưới.
  5. Điền 6 thông số + Mã truy cập tự đặt vào form dưới đây, bấm "Lưu & Kết Nối".
  6. Gửi lại đúng 6 thông số này cho các cán bộ/thiết bị khác để họ cấu hình y hệt. Mỗi cán bộ sau đó tự Đăng ký tài khoản bằng email riêng; Quản trị viên vào mục "Quản Lý Tài Khoản" để cấp vai trò phù hợp cho từng người.
  7. Tài khoản đầu tiên cần được cấp vai trò admin thủ công: vào Firestore Console → collection hoabinh_users → mở đúng tài khoản đó → sửa trường role thành admin.
Mẫu Security Rules cần dán vào Firestore → Rules (yêu cầu đăng nhập để ghi dữ liệu):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function role() {
      return get(/databases/$(database)/documents/hoabinh_users/$(request.auth.uid)).data.role;
    }
    match /hoabinh_system/{docId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
        && role() in ['admin','van_phong','mot_cua','kiem_tra','khao_sat'];
    }
    match /hoabinh_users/{uid} {
      allow read: if request.auth != null;
      // Tự đăng ký chỉ được ở quyền "viewer"
      allow create: if request.auth != null && request.auth.uid == uid
        && request.resource.data.role == 'viewer';
      // Chỉ admin được đổi vai trò; người dùng không tự nâng quyền
      allow update: if request.auth != null && role() == 'admin';
    }
  }
}
